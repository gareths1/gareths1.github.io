## Features

- A species list and lookup by species ID
- A random penguin endpoint
- A "penguin of the day" that is the same for everyone on a given date
- An automated bot that posts the daily penguin to [Discord/Bluesky]
- Interactive API documentation generated by FastAPI

## API endpoints

| Endpoint | Description |
|---|---|
| `GET /api/v1/penguins` | List all penguin species |
| `GET /api/v1/penguins/{species_id}` | Get one species |
| `GET /api/v1/penguins/random` | Get a random penguin |
| `GET /api/v1/penguins/daily` | Get the penguin of the day |
